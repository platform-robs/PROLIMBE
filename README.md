# 🧼 PROLIMBE | Productos de Limpieza Swipe

Sitio web oficial de **PROLIMBE**, una tienda especializada en la **venta y distribución de productos de limpieza de la marca Swipe**, orientados tanto al **hogar** como a **clientes institucionales y comerciales** dentro del estado.

---

## 📌 Descripción del proyecto

Este repositorio contiene el código fuente de un **sitio web estático, profesional y moderno**, diseñado para fortalecer la presencia digital de PROLIMBE, transmitir confianza a los clientes y apoyar el proceso de venta de productos de limpieza.

El sitio está enfocado en:

* Presentar claramente la marca PROLIMBE
* Comunicar el valor de los productos Swipe
* Facilitar la consulta de productos y promociones
* Brindar canales de contacto claros y confiables

El diseño prioriza una **experiencia limpia, visualmente agradable y funcional**, alineada con el sector de limpieza profesional.

---

## 🗂️ Estructura del proyecto

```
/prolimbe-web
│── index.html        # Página de inicio
│── promociones.html  # Promociones y ofertas
│── productos.html    # Catálogo de productos
│── contacto.html     # Información y formulario de contacto
│── estilos.css       # Estilos globales del sitio
│── /assets           # Imágenes y logotipos
```

---

## 🚀 Tecnologías utilizadas

* **HTML5** – Estructura semántica
* **CSS3** – Diseño moderno y responsivo
* **JavaScript (Vanilla)** – Interacciones (menú, modal, scroll)

> No se utilizan frameworks ni librerías externas para mantener el proyecto ligero y fácil de mantener.
